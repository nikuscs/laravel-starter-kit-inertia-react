# Create New Component

Build components that stay presentational. Keep pages thin — real UI belongs in components.

## 1. Place the File Correctly

Components go in `resources/js/components/`:

- Domain components: `components/orders/order-list.tsx`
- Shared components: `components/shared/status-badge.tsx`
- UI primitives: `components/ui/` (do NOT add here — these are Shadcn)

Filename: kebab-case. Export: PascalCase.

## 2. Forward Props by Default

Simple components should forward native props and merge `className` with `cn()`.

```tsx
import { cn } from '@/lib/utils';
import type { ComponentProps } from 'react';

export function SectionTitle({ className, ...props }: ComponentProps<'div'>) {
    return <div className={cn('flex items-center gap-2', className)} {...props} />;
}
```

For domain components with data props, use a clear props interface:

```tsx
interface OrderListProps {
    orders: App.Models.Order[];
}

export function OrderList({ orders }: OrderListProps) {
    return (
        <div className="space-y-4">
            {orders.map((order) => (
                <OrderCard key={order.id} order={order} />
            ))}
        </div>
    );
}
```

## 3. Types Come From Inertia Shared Data

Use the types generated by Laravel/Inertia in `resources/js/types/`:

```tsx
// Types from Inertia page props
interface Props {
    order: App.Models.Order;
}
```

Do not redefine server response shapes inside component files.

## 4. Use Existing Shadcn/ui Primitives

Before creating a new component, check `resources/js/components/ui/` for existing primitives:

- `button.tsx`, `card.tsx`, `dialog.tsx`, `input.tsx`
- `select.tsx`, `badge.tsx`, `avatar.tsx`
- `dropdown-menu.tsx`, `sheet.tsx`, `tooltip.tsx`

Do not modify these files. Compose them.

## 5. React Rules

- No `useMemo`, `useCallback`, `React.memo` — React Compiler handles it
- Use Inertia `useForm` for form state, not local state
- Use Inertia `Link` or Wayfinder helpers for navigation
- Use `cn()` from `@/lib/utils` for class merging

## 6. Keep Components Focused

- Pages should be thin wrappers
- Forms should be dedicated components
- Lists with complex items should extract the item component
- If a file grows past ~300 lines, look for extraction boundaries

## 7. Avoid These Mistakes

- No inline label maps or variant maps — extract to a shared location if needed
- No inline utility helpers for formatting or transforms
- No duplicated server data interfaces
- No hardcoded English strings where i18n might be added
- No non-composable components that drop `className`

## 8. Final Check

1. File is in the right directory
2. Props are forwarded when composable
3. Existing Shadcn/ui primitives are used
4. No manual memoization
5. `className` merging with `cn()` where applicable
